How this page is supposed to die

The kernel pages state present tense. They do not say “formerly Code Mode.” They say PTC, because that is the name the registry owns. This apparatus is the only page allowed to talk about the interval.

A later sitting folds every lemma below into the body — or drops it if the body already carries the fact — and starts a blank addenda. Until that sitting, a reader who still has edition 1 in their head can walk the list instead of rereading the atlas.

Official contracts still win on conflict: docs/architecture.md, package READMEs, generated catalogs, implemented Agent Notes. This page is a reading aid, not a changelog of 2470 commits.

Corrigenda — edition 1 said this; the body no longer does

C1

The presentation mode is ptc, not code

Edition 1 called the reserved run_code transport “Code Mode” and wrote tools.mode as native | code | both. The registry’s closed union is native | ptc | both. Cloudflare’s essay still names the observation; the product name is PTC. Durable sub-dispatch events keep the historical types tool/code-dispatch-start / tool/code-dispatch. The live waterfall is tools/ptc-dispatch-log.

C2

dsh-base is not the first layer of every profile

Edition 1 said every profile stacks dsh-base. web, headless, sdk, and acp do. sdk-minimal is the deliberate exception: one bundle owns its complete explicit tree and does not apply base.

C3

Shipped templates are five, not two

Edition 1 named web and headless. The architecture map now ships web, headless, sdk, sdk-minimal, and acp. Custom profiles default to live patch reload. Shipped web is live; the one-shot and stdio profiles apply layers once at startup.

C4

request/header has a fourth reason

Edition 1 listed initial, resume, and change. An enter decision may now set startsRequestSeries. The loop then logs reason series, or change carrying startsSeries: true when the envelope changed too. Wrapping agent/pre-step listeners must spread the decision so the flag survives.

Addenda — new facts the body now carries

A1

Every supported Node application starts at dsh

There is no second executable for the SDK, and no inline Cordis tree from a caller. dsh web is the alias for --profile web. The TypeScript SDK resolves its same-version dsh and selects sdk. Python’s runtime wheel packages that CLI and launches dsh --profile sdk with an explicit Harness home. Persistent external plugins install through dsh plugin. A gate refuses a Node application path that bypasses this launcher. The private browser WebWorker preview is not a launcher.

A2

Projections are a required host seam

dsh-session-projection owns ctx.sessionProjections. Host readers require the registry and the key, or they fail at activation or first access. They read one typed state with stateOf(). Carriers batch cropped client views with snapshot(). Host fold state and client views are independently typed. The agent loop registers shared turnBoundary state. The web turn rail reads a whole-log turnOutline unit so paging does not require the entire event body.

A3

Event identities are not log offsets

SessionSeq names an existing event. SessionLogOffset names a gap, prefix length, or read cut and may equal the event count. The compiler refuses to interchange them. The logical header carries isSeeded rather than a numeric seed cut; body-bearing observations keep inheritedEventCount. On-disk v0 JSONL stays byte-compatible. Public wires still carry ordinary numbers; adapters brand at the same-process edge.

A4

Webhooks start ordinary Sessions and then forget them

ctx.webhookRuntime is a capability on the architecture map. A trusted rule returns null or one Workspace-backed Session request. Dispatch is process-local and fire-and-forget: no delivery database, queue, retry, or Agent-completion state. dsh-webhook-github verifies X-Hub-Signature-256 on an isolated WebServer so the webhook port need not expose /api. A 202 means verified in-memory dispatch, not “the Agent finished.”

A5

Agent Teams incubate outside the release family

packages/experimental/ is a group with mechanical exclusion from pack and publish. Agent Teams is a private opt-in on ctx.agentTeams: a durable roster, mailbox, and compare-and-set task board over continuable children. The default tool catalog does not change. Released products must not depend on experimental packages. Promotion is a rename, not a flag.

A6

The PTC preset hides the general workflow tool

The shipped ptc preset sets mode: ptc and disables tool-workflow so the model does not get a second orchestration surface beside run_code. The worker-thread engine and Ralph stay mounted. standard and cordis still publish workflow.

A7

Base enables web_fetch

Shared dsh-base mounts dsh-tool-web with fetch: true. Search stays DeepSeek-official; fetch is anonymous HTTP(S) with destination pinning. Products with a stricter network policy override the row. The web app still composes the tool per agent preset rather than as a host singleton.

A8

@file mentions are a seam, not an attachment

ctx.fileReferences offers path candidates. Picking one inserts mention text. It does not read the file. The model still has to call a filesystem tool. A local provider ranks against the agent’s working directory. Session Controller exposes fileReferences/list to the browser.

A9

Official DeepSeek can take a Session-log suffix

dsh-session-log-deepseek is mounted dormant. When enabled it owns the dsh_session_log request field and an acceptance watermark. Upload is at-least-once. Forks ignore inherited parent watermarks. Direct requests without a live Session omit the field.

A10

Authorization is a conversation with a human

dsh-authorization registers flows that configuration cannot supply: sign-in, a pasted code, a question. An attempt reports authorized only after the credential record commits. A withdrawn attempt is cancelled, not an error. Headless may mount the package; nothing asks unless a plugin registered a flow.

A11

External informational events may carry ignorable: true

First-party Session.append still does not set the marker. A repository-external plugin is an allowed consumer. An unknown required event still refuses resume. Default-required remains the failure mode the design prefers.

A12

Demo bundles left packages/examples

Runnable leaves live under repo-root examples/. The workspace group that used to hold them is gone. Profile bundles dsh-web-app, dsh-headless, dsh-sdk-app, dsh-sdk-minimal, and dsh-acp-app live under packages/bundle/.

Left in this appendix on purpose

Not every interval change is a bet. Chat scroll throttling, keyed conversation sources, superellipse corners, Safari textarea reflow, and SQLite physical chunk compression belong in package notes and UI snapshots. They do not rewrite the ontology. Edition 3 should not grow kernel pages for them unless a later change makes one of them load-bearing.

Experimental Inspector, CPython code-runtime, and the browser-worker preview are real and private. The atlas names the group. They stay out of the kernel pages until promotion.

Homes for the lemmas: docs/architecture.md, packages/core/tools, packages/webhook, packages/experimental, and the Agent Notes on projections, seq brands, fire-and-forget webhooks, and experimental package exclusion.
