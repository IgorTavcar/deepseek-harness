seq 0009 fragments that carry an invariant

Small functions that refuse a whole class of bugs.

These are not clever tricks. They are places where a race, a desync, or a silent veto was made locally impossible. Line numbers move; the idea should not.

1. Claim is two pure deletions

packages/core/agent/src/inbox.ts — drain next-step, then at most one next-turn, then notify. Durable splice first. Claimed work cannot be put back by a listener.

claim(target: InboxTarget, turn: number): UserMessage[] {
  const claimed = this.mutate('next-step', 0, this.nextStep.length, [], false)
  if (target === 'next-turn') {
    claimed.push(...this.mutate('next-turn', 0, 1, [], false))
  }
  for (const message of claimed) this.notifications.claimed(message, turn)
  return claimed
}

2. Classify wake before the insert

agent-loop/src/agent.ts — a splice observer can cancel reentrantly. Capture “waking after abort” first, force that item onto next-turn, then insert. The wake cannot be reclassified into the dying activity.

const wakingAfterAbort = wakeup && this.phase.kind !== 'idle'
  && this.phase.abort.signal.aborted
const resolvedTarget = wakingAfterAbort ? 'next-turn' : target
this.inbox.splice(resolvedTarget, Infinity, 0, [message])
if (wakeup) this.wakeDriver(wakingAfterAbort)

3. whenIdle chases replacement drivers

Latch replay can start a new activityDone while you await the old one. Loop until the promise you just awaited is still the current one.

async whenIdle(): Promise<void> {
  let activity: Promise<void>
  do {
    await (activity = this.activityDone)
  } while (activity !== this.activityDone)
}

5. Strip adapter defaults so the next route rematerializes them

A Flash default of high effort must not leak onto a model that has no reasoning. Marked fields are deleted from the proposal. Unmarked explicit settings persist.

function requestProposal(header: EpochHeader): LlmCallConfig {
  if (header.adapterDefaults === undefined) return header.config
  const proposal = { ...header.config }
  if (header.adapterDefaults.reasoningEffort === true) delete proposal.reasoningEffort
  if (header.adapterDefaults.maxTokens === true) delete proposal.maxTokens
  return proposal
}

8. Only exact true overlaps

Fail-closed concurrency. Throw, undefined, or a confused classifier becomes a barrier. Re-read immediately before start.

executionMode(exec: ToolExecutionInput): ToolExecutionMode {
  const tool = this.resolveExecution(exec.name, exec.agent, exec.parent !== undefined)
  if (!tool?.isConcurrencySafe) return { kind: 'exclusive' }
  try {
    const concurrencySafe: unknown = tool.isConcurrencySafe(exec.arguments)
    return concurrencySafe === true ? { kind: 'parallel' } : { kind: 'exclusive' }
  } catch {
    return { kind: 'exclusive' }
  }
}
