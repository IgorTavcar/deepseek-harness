Everything is a plugin. The conversation is a log.

DeepSeek Harness is not a ReAct script with a plugin folder stapled on. It is a Cordis fiber tree whose loop, model adapter, tools, session, UI, and even the agent that rewrites the runtime are the same kind of thing.

edition 2 · 0.1.2-alpha.4 developer preview MIT · DeepSeek AI target: V4 Flash / V4 Pro

This wiki is an unofficial juice press of the repository. Official contracts live in docs/ and the package READMEs. Here the job is different: name the bets, walk the machine, and show why a swap of ctx.fs plus ctx.subprocess can move Bash, a PTY, and an LSP into another Linux without forking the loop.

The thesis in four sentences

  1. A running dsh is an empty plugin list plus ordered patches. There is no privileged core to monkey-patch.
  2. A session is an append-only event log. Message history is a fold. Anything the model sees must be reconstructable from that log.
  3. The default driver is one plugin, dsh-agent-loop. Policy, compaction, retry, sandbox, persona, and UI sit on waterfalls and session events, not inside the driver.
  4. A capability is a seam: Service Definition, Service Provider, Consumer. One provider swap changes the product; the model-facing schema stays still.

Model-visible means logged. A new input the model can see requires a new session event. The live invariant reconstructs the frozen request and compares it at llm/stream.

Aspects

seq 0002

The harness loop

Turn, step, inbox, claim. Followup wakes a new turn. Steer hits the next step. Inject waits. Tools that ran without concluding the turn force another model request even when the inbox is empty.
seq 0003

Plugin logic

Cordis context, inject, typed events, reversible effects. Waterfalls are around-middleware: forget next() and you have vetoed the universe. Profiles stack bundles as a patch algebra.
seq 0004

Session as truth

Chunks for the UI, assembled messages for history, compaction as a surface replace rather than a rewrite of the past. Unknown required events refuse resume. Silent amnesia is the failure this design forbids.
seq 0005

Tools and PTC

A guarded pipeline, monotonic owner policy, canonical JSON values that never hit the log, and a reserved run_code transport so the model can write TypeScript against a generated PTC SDK.
seq 0006

Capability seams

Shell, filesystem, subprocess, sandbox, subagent, workflow, LLM. One execution world. Point fs and subprocess at E2B and the tools keep their names.
seq 0007

Target models

Shipped conversation models are DeepSeek-V4-Flash and DeepSeek-V4-Pro on route deepseek-official. A second adapter, pi-ai, stays dormant until settings add Anthropic, OpenAI, gateways, or another DeepSeek path.
seq 0008

Surprising ideas

Scopes that are not sandboxes. Plan mode that is a boolean fold. Ralph that is not a goal. Hooks that are bridges, not the ontology. Invariants that refuse “the plugin exists.”
seq 0009

Diamonds in the code

Twelve tight fragments: claim as two deletions, whenIdle chasing replacement drivers, adapter defaults stripped so the next route rematerializes them, abort pairs that keep the transcript legal.
seq 0010

Against other harnesses

Claude Code and Codex are products with hook dialects. This repository implements those dialects as plugins on a richer native surface. LangGraph graphs a conversation; Cordis fibers a runtime.
seq 0011

The agent rewrites itself

demo:cordis hands the model inspect, define, run, and stop over the live tree. Typert generated catalogs meet the live service store. Trust is bash-equivalent, not a security boundary.
seq 0012

Continuation policies

Same-session goals, fresh-agent Ralph rounds, model-authored workflows, and plan state that is not a mode registry. Subagents can be other products: Codex, Claude Code, ACP, or another dsh.
seq 0013

Package atlas

The group map, the base bundle, profiles, presets, and where new behavior attaches. Use this when you already know the story and need the directory.
