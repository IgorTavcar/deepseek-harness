A directory of groups, not a second module graph.

The generated graph is docs/module-graph.md. This page is a reading map: what each group is for, and where a new behavior goes. npm names stay @deepseek-ai/dsh-<pkg> regardless of folder.

What boots

Layers on an empty include: dsh-base, then the profile's other bundles (dsh-web-app or dsh-headless), then profile patch, home patch, --patch. Base inserts model adapters, default model selection, tools, persistence, policy, settings, credentials, telemetry, and host-level subagent providers. Codex and Claude Code providers load dormant. On Windows the same patch disables bash and mounts pwsh; on POSIX the inverse. Both families register ctx.shell, so an incomplete override fails loud.

Runnable leaves live under examples/. pnpm dsh --profile headless "task" runs from source through tsx's ESM hook. Modules that path reaches must stay ESM.

Three faces of the same tree

Web

npx @deepseek-ai/dsh web or pnpm dsh web. Host API proxy plus a plugin-composed browser client. Default port 3080.

Headless / CLI

One-shot runner, no server. ACP automation server for editors. JSON-RPC SDK and a Python package that speaks it.

The agent itself

Source-launch through tsx. Snapshot tests replay assembled examples without a key. e2e talks to the real API when DEEPSEEK_API_KEY is set.

Official homes

  • docs/architecture.md — the ordered map you read before changing packages/.
  • docs/subsystems/ — types, semantics, generated Cordis API regions.
  • docs/cookbook/ — adding a package, tool, adapter, or conversation node.
  • docs/user/ — product guides, including model configuration.
  • .agents/notes/implemented/ — why, what was given up, what pins the decision.

This wiki is not those documents. It is a static atlas for walking the bets in one sitting. When a fact and a README disagree, the README and the generated catalogs win.
