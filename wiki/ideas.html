seq 0008 the bets that are not obvious

The ideas that do not fall out of “write a ReAct loop.”

Each of these is a decision someone could have made the other way. Most harnesses did. The Agent Notes record what was given up.

The loop is a plugin

There is no god-object Agent to subclass. dsh-agent owns the handle and events. dsh-agent-loop registers a factory. Changing the driver is composition. Changing behavior is almost never changing the driver.

Forget next() and you have vetoed the turn

The framework will not save an observer who treats a waterfall like emit. That is documented, tested, and still easy to get wrong. They treat it as a teaching problem, not a footgun to hide.

Claim first, then decide

The inbox is durable. Pre-step cannot put claimed messages back. A rejected turn still exists. Inject after the claim misses this request. Unusually honest about what the model can still see.

Turn-stopping is data

agent/turn-stopping is serial and has no next(). Listeners object by steering. The machine re-reads the inbox. Listener order cannot close or keep the turn.

Guards are monotonic

The pre-execute waterfall is reorderable. Owner policy that must not be reordered is tools.guard(). Later listeners cannot turn a denial back into permission. Hooks stay generic; identity-sensitive policy stays a guard.

Plan mode is a boolean fold

They deleted a generic named-mode framework. plan/mode: { active } is a log event. Sandbox mode and approval are separate axes and do not read plan state. exit_plan_mode stays registered when inactive so tool schemas — and the KV cache — stay stable.

Three continuation policies, none in the loop

Goals are same-session durable objectives. Ralph is a fresh child each round with the workspace as memory. Workflows are model-authored scripts over agent(). Typical products smash these into one “task mode.”

Subagents can be other products

Providers include spawn, fork, ACP, real Codex, real Claude Code, and out-of-process dsh. Delegation is not an Agent method. You can farm work to Claude Code without forking this loop.

Hooks are bridges

The native surface is typed Cordis events. hooks-claude-code and hooks-codex translate existing hooks.json dialects onto that surface. Compatibility without making shell hooks the ontology.

Scopes are not sandboxes

Per-agent visibility and lifetime, explicitly not authority. Security that must hold is approval, sandbox policy, and monotonic guards. Using scope as a permission system would be a category error the note forbids.

Typert is the API the model reads

A compiler-independent type graph generated from host and client programs feeds docs, cordis_inspect, and the RPC gateway. The inspecting agent reads generated truth about the source, intersected with the live service store. Not a handwritten skills file of APIs.

Invariants check relationships, not presence

Every workspace package publishes ./invariant. A companion either checks an event or data relationship or is empty with a comment explaining why. Forbidden: “plugin name matches,” “method exists,” “pure function still returns 2.” A gate makes ownership exhaustive.

Complete prompt sections

One complete: true section after assembly is the entire system prompt. Multiple complete sections reject assembly. Interpolation is strict: unknown variables throw. A lone {{ with no closer passes through.

Model Experience is a README section

Every package that can affect the model documents what the model sees, the token effect, and the KV-cache effect. Prefix stability is a design input, not an ops surprise.

The agent may grow new fibers

demo:cordis is not a party trick. Because everything is a plugin, inspect and mount are the same algebra as boot. Temporary plugins are process memory, bash-equivalent trust, fully disposable. The surprising part is that disposal is already solved.

Pre-release honesty as versioning

SESSION_FORMAT_VERSION stays at 0. Rename freely. Backends reject old disks. No shims. The first tagged release is when this paragraph gets deleted from AGENTS.md.
