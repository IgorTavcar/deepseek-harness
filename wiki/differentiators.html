seq 0010 against the field

Other harnesses are products with extension dialects. This one is a runtime ontology that happens to ship a product.

Claude Code and Codex are excellent products. DeepSeek Harness implements their hook dialects as plugins. That inversion is the differentiator. The loop is not the product. The dumpable, disposable, inspectable tree is.

Claude Code and Codex, specifically

Those products invented hook files, permission prompts, and plan-like collaboration that users already have. DeepSeek Harness does not ask those users to learn a new shell protocol. It translates the dialects onto typed events and keeps the richer native surface for everything else.

It also goes the other way: dsh-subagent-claude-code and dsh-subagent-codex spawn those products as children. The harness can be the control plane while another vendor's agent does a slice of work. That is a stranger move than “we have hooks too.”

Against agent frameworks

LangGraph, AutoGen, CrewAI, and friends optimize for authoring a graph of model calls. DeepSeek Harness optimizes for a long-lived coding agent with a durable log, a permissioned execution world, a web GUI, ACP automation, and a plugin tree that can be dumped, patched, and hot-reloaded. You would not pick this repository to sketch a five-node research graph. You would pick it to own the product that sits on a developer's machine for hours and must resume, fork, compact, and explain itself.

The cost is real: more packages, more ceremony, capability-seam boilerplate, generated catalogs, bilingual official docs, 100% coverage on packages/*/*/src. The return is that a new backend does not churn the model-facing contract, and a new behavior does not require a loop patch.

Why this exists at DeepSeek

The native adapter is not a thin OpenAI wrapper. Thinking-plus-tools passback, empty first reasoning chunks, cache-hit arithmetic, session-title thinking kill-switch, compact attribution, anonymous user headers — those are DeepSeek-wire facts encoded so V4 Flash and V4 Pro stay reconstructable. The pi-ai twin exists so the same loop can speak other providers without lying about what the vocabulary can express.

The default persona-less prompt, PTC, and the self-referential cordis tools are bets about what strong reasoning models actually want: less hidden prose, more structured calling conventions, and the ability to extend the runtime when the built-in tool set is the bottleneck.
